02 App Description & Features

ProLocker is a multi-feature security and utility application that provides:

🔒 App Locking

  • Lock applications using a PIN code, lock pattern, or fingerprint/biometrics.
  • Customizable lock screen overlay, themes, and backgrounds.
  • Optional intruder selfie capture upon repeated failed unlock attempts.

📞 Call Blocker

  • Block incoming calls from designated blacklists or unknown numbers.
  • Operates via Android Call Screening Service and Phone State monitoring without recording audio.

💾 Backup & Restore

  • Back up and restore your contacts to local storage files (.vcf format).
  • Back up installed applications by exporting APK packages to local storage.

🗄️ File Vault & Junk Cleaner

  • Securely hide sensitive photos, videos, audios, and documents in a private local vault.
  • Scan and clean cache, residual files, and obsolete APKs to free up device storage.
