02 Description of the App

ProLocker is a comprehensive device security application that provides:

🔒 App Locking

  • Lock individual apps with a PIN code, lock pattern, or biometric authentication
  • Display a customizable lock screen overlay when a locked app is opened
  • Optional intruder photo capture on failed unlock attempts
  • Customizable lock screen backgrounds and wallpapers

📞 Call Blocker

  • Block incoming calls from specific numbers or unknown callers
  • Automatically reject calls matching your defined rules
  • Works via Android's Call Screening Service (Android 10+) and Phone State monitoring

💾 Data Backup

  • Back up and restore your contacts to/from local storage
  • Back up and restore your call logs to/from local storage
  • Back up SMS messages to a local file on your device

🧹 Performance Tools

  • RAM / memory cleaner to free up device memory
ProLocker uses an Accessibility Service, Usage Stats permission, and Phone State monitoring to deliver its core features. These are used exclusively for the security and utility functions described above.
